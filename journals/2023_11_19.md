- de-escalation techniques
	- starting the conversation
	  | to convey | instead of | try this |
	  | ----------- | ----------- | -------- |
	  | feeling unheard | "You never listen to me," | "I feel like we're not really connecting lately. Can we set aside some time to really listen to each other and share what's going on?"|
	  | frustration | "You're always messing things up," | "I get frustrated when things don't go as planned. Can we talk about how we can work together more effectively in the future?" |
	  | | blame | "Let's take a moment to cool off before we continue the conversation." |
	  | | guilt | "I want to make sure we're both feeling respected and valued." |
	  | | reacting coldly | "Can we pause and take a step back to think through our options together?" |
	  | feeling needs unmet | "You're so inconsiderate," | "I feel like my needs aren't being considered. Can we talk about how we can make decisions together that work for both of us?" |
	  | disagreement | asking for changes | "I understand you have a different perspective, can you share more about why you feel that way?" |
	  | | | "I see things differently, but I'm open to hearing your perspective. Can you tell me more about your thoughts?" |
	  | | | "Let's try to find a solution that works for both of us. How can we compromise here?" |
	  | | | "I respect your feelings and want to work this out. Can we talk about how we can both feel heard and respected?" |
	  | | | "I appreciate your honesty, and I value our relationship too much to let this divide us." |
	  | disappointment | reacting coldly | "Thanks for being honest and communicating your feelings with me. I care about you and I'm fine with anything you decide. We can work through this together, I know it. |
- "Good Enough" journal
  template:: "Good Enough" journal
	- name of task or project
	- brief description
	- rating from "not good enough" (1) to "totally good enough" 10
	- reason for rating
	- insights or takeaways

- admonition blocks:
	- #+BEGIN_TIP
	  this is a pre-formatted tip using `<Tip`
	  #+END_TIP
	- #+BEGIN_IMPORTANT
	  this is a pre-formatted important block with `<Important`
	  #+END_IMPORTANT
	- #+BEGIN_CAUTION
	  use `<Caution` to get this block
	  #+END_CAUTION
	- #+BEGIN_WARNING
	  use `<Warning` to get this block
	  #+END_WARNING
	- #+BEGIN_EXAMPLE
	  use `<Example` to get this block
	  #+END_EXAMPLE
	- #+BEGIN_VERSE
	  use `<Verse` to get this block style (preserve a new line)
	  #+END_VERSE
	- [#A] important `[#A]`
	- [#B] less important `[#B]`
	- [#C] even less important `[#C]`
	- **Bold** `**Bold**`
	- _Italic/cursive_ `_italic/cursive_`
	- <ins>Underline</ins> `<ins>Underline</ins>`
	- ~~Strikethrough~~ `~~S~~`
	- ^^Highlight^^ `^^H^^`
	- `code` \`code\`
	- \```plain
	  more code
	  ```

	  creates a comment block `<Comment`
	  #+END_COMMENT
